# SkillBridge AI – Career Intelligence Platform (Android)

SkillBridge AI is a native B.Tech-level Android application built with **Kotlin**, **Jetpack Compose**, and **Material 3**. It empowers engineering students to analyze skill gaps, optimize resumes for campus placements, follow a customized learning roadmap, practice DSA/Java, and prepare for interviews.

## 🛠️ Architecture & Tech Stack
- **Language**: Kotlin 2.0+
- **UI Toolkit**: Jetpack Compose with Material 3 Design
- **Architecture**: MVVM with Repository Pattern and Coroutines/StateFlow
- **Local Persistence**: Room SQLite Database + DataStore Preferences
- **Dependency Management**: Gradle Kotlin DSL (.kts)
- **Networking**: Retrofit 2 + OkHttp (configured for Spring Boot REST API integration)
- **AI Career Mentor**: Extensible Gemini AI Client abstraction with offline fallbacks

## 🚀 How to Open & Run in Android Studio
1. Open Android Studio (Ladybug / Iguana or later).
2. Select **Open**, and navigate to this extracted folder.
3. Allow Gradle sync to download dependencies.
4. Run on an Android 14/15 Virtual Device (e.g. Pixel 8) or physical device via USB debugging.

Designed and engineered for B.Tech placement readiness.
